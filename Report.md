# Отчёт по итогам тестирования приложения «Путешествие дня»

## Краткое описание

В рамках дипломного проекта было проведено автоматизированное тестирование веб-приложения «Путешествие дня».

Проверялись:

- покупка тура по дебетовой карте;
- покупка тура в кредит;
- валидация полей формы;
- обработка карт со статусами APPROVED и DECLINED;
- корректность сохранения информации об операциях в базе данных.

Для автоматизации использовались Java, JUnit 5, Selenide, Gradle, JDBC и Allure. Для запуска банковского симулятора и
базы данных использовались Docker и Docker Compose.

## Результаты тестирования

Всего было выполнено 17 автоматизированных тестов.

Результаты выполнения:

- успешно пройдено — 14 тестов;
- завершилось с ошибкой — 3 теста;
- доля успешно пройденных тестов — 82,35 %.

Три теста завершились с ошибкой вследствие обнаруженных дефектов тестируемого приложения.

## Обнаруженные дефекты

### 1. Некорректная обработка DECLINED-карты при оплате

При попытке оплаты картой со статусом DECLINED приложение отображает сообщение об успешной операции вместо сообщения об
отказе.

Банковский симулятор при этом возвращает статус DECLINED.

Дефект выявляется автоматизированным тестом `shouldNotPayWithDeclinedCard()`.

Ссылка на GitHub Issue: https://github.com/missgradova-hue/Diplom/issues/1

### 2. Некорректная валидация поля «Владелец»

Поле «Владелец» принимает цифровое значение `12345`. После отправки формы приложение не отображает ошибку валидации и
позволяет выполнить операцию.

Дефект выявляется автоматизированным тестом `shouldShowErrorWithInvalidHolder()`.

Ссылка на GitHub Issue: https://github.com/missgradova-hue/Diplom/issues/2

### 3. Некорректная обработка DECLINED-карты при покупке в кредит

При покупке тура в кредит с использованием карты со статусом DECLINED приложение отображает сообщение об успешной
операции вместо сообщения об отказе.

При этом банковский симулятор и база данных фиксируют статус операции DECLINED.

Дефект выявляется автоматизированным тестом `shouldNotCreditWithDeclinedCard()`.

Ссылка на GitHub Issue: https://github.com/missgradova-hue/Diplom/issues/3

## Проверка взаимодействия с базой данных

В ходе тестирования была выполнена проверка сохранения результатов операций в базе данных MySQL.

Автоматизированными тестами проверено сохранение статусов:

- APPROVED при успешной оплате;
- DECLINED при отклонённой оплате;
- APPROVED при успешной покупке в кредит;
- DECLINED при отклонённой покупке в кредит.

Для получения данных из базы использовалось JDBC-подключение.

Проверка показала, что статусы операций сохраняются в базе данных корректно. При этом были обнаружены расхождения между
статусом операции, полученным от банковского сервиса, и уведомлением, отображаемым пользователю.

## Отчёт Allure

Для формирования отчёта о выполнении автоматизированных тестов используется Allure.

По результатам итогового запуска:

- всего выполнено 17 тестов;
- успешно выполнено 14 тестов;
- завершилось с ошибкой 3 теста;
- процент успешных тестов — 82,35 %.

Три неуспешных теста соответствуют обнаруженным и зарегистрированным дефектам приложения.

Для просмотра отчёта после выполнения тестов необходимо выполнить:

`.\gradlew allureServe`

## Общие рекомендации

По результатам проведённого тестирования рекомендуется:

- исправить обработку операций со статусом DECLINED, чтобы выводилось сообщение об отказе вместо сообщения об успешной
  операции;
- усилить валидацию поля «Владелец», исключив возможность ввода цифровых и других некорректных значений;
- после исправления обнаруженных дефектов выполнить повторный запуск автоматизированных тестов;
- продолжить использование автоматизированных тестов при внесении изменений в приложение для контроля основных сценариев
  оплаты и покупки в кредит.

## Общий итог

Основные сценарии работы приложения были автоматизированы и проверены.

По результатам запуска 17 автоматизированных тестов успешно пройдено 14 тестов, 3 теста завершились с ошибкой из-за
обнаруженных дефектов приложения.

Обнаруженные дефекты зарегистрированы в GitHub Issues. Результаты выполнения автоматизированных тестов представлены в
отчёте Allure.
