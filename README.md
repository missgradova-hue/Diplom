# Дипломный проект по профессии «Тестировщик»

## Автоматизация тестирования приложения «Путешествие дня»

Проект содержит автоматизированные тесты веб-приложения «Путешествие дня».

В приложении доступны два способа покупки тура:

- оплата по дебетовой карте;
- покупка в кредит.

Автоматизированные тесты проверяют пользовательский интерфейс, валидацию полей, обработку банковских операций и
сохранение результатов операций в базе данных.

Тестирование поддерживает работу приложения с двумя СУБД:

- MySQL;
- PostgreSQL.

## Используемые технологии

- Java 11
- Gradle
- JUnit 5
- Selenide
- JDBC
- MySQL
- PostgreSQL
- Awaitility
- Docker
- Docker Compose
- Allure

## Предварительные требования

Перед запуском необходимо установить:

- Java 11;
- Docker Desktop;
- Git.

## Запуск Docker-контейнеров

В корневой папке проекта выполнить:

```bash
docker compose up -d
```

Для проверки состояния контейнеров:

```bash
docker compose ps
```

Должны быть запущены:

- банковский симулятор;
- MySQL;
- PostgreSQL.

Банковский симулятор доступен на порту `9999`.

MySQL доступен на порту `3306`.

PostgreSQL доступен на порту `5433`.

---

## Запуск и тестирование с MySQL

### 1. Запуск приложения

В отдельном терминале из корневой папки проекта выполнить:

```bash
java -jar aqa-shop.jar
```

По умолчанию приложение использует MySQL:

```text
jdbc:mysql://localhost:3306/app
```

После успешного запуска приложение будет доступно по адресу:

http://localhost:8080

Терминал с запущенным приложением необходимо оставить открытым.

### 2. Запуск тестов

В новом терминале выполнить:

```bash
./gradlew clean test
```

Для Windows PowerShell:

```powershell
.\gradlew clean test
```

## Запуск и тестирование с PostgreSQL

### 1. Запуск приложения

Для запуска приложения с PostgreSQL выполнить:

```powershell
java -jar aqa-shop.jar --spring.datasource.url=jdbc:postgresql://localhost:5433/app --spring.datasource.username=app --spring.datasource.password=pass
```

После успешного запуска приложение будет доступно по адресу:

http://localhost:8080

Терминал с приложением необходимо оставить открытым.

### 2. Запуск тестов

Для Windows PowerShell:

```powershell
.\gradlew clean test "-Ddb.url=jdbc:postgresql://localhost:5433/app" "-Ddb.user=app" "-Ddb.password=pass"
```

Параметры подключения передаются в тесты через системные свойства Gradle.

Таким образом, один набор автотестов может использоваться как для MySQL, так и для PostgreSQL без изменения исходного
кода.

> Часть тестов может завершаться с ошибкой вследствие обнаруженных и зарегистрированных дефектов тестируемого
> приложения.

## Формирование отчёта Allure

После выполнения тестов запустить:

```bash
./gradlew allureServe
```

Для Windows PowerShell:

```powershell
.\gradlew allureServe
```

После формирования отчёт Allure автоматически откроется в браузере.

В Allure используются аннотации и человекочитаемые названия тестовых сценариев.

Для остановки сервера Allure необходимо нажать `Ctrl + C` в терминале.

## Тестовые карты

Для тестирования используются следующие карты:

- `4444 4444 4444 4441` — статус `APPROVED`;
- `4444 4444 4444 4442` — статус `DECLINED`.
