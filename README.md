# Дипломный проект по профессии «Тестировщик»

## Автоматизация тестирования приложения «Путешествие дня»

Проект содержит автоматизированные тесты веб-приложения «Путешествие дня».

В приложении доступны два способа покупки тура:
- оплата по дебетовой карте;
- покупка в кредит.

Автоматизированные тесты проверяют пользовательский интерфейс, валидацию полей, обработку банковских операций и сохранение результатов операций в базе данных.

## Используемые технологии

- Java 11
- Gradle
- JUnit 5
- Selenide
- JDBC
- MySQL
- Docker
- Docker Compose
- Allure

## Предварительные требования

Перед запуском необходимо установить:

- Java 11;
- Docker Desktop;
- Git.

## Запуск проекта

### 1. Запуск Docker-контейнеров

В корневой папке проекта выполнить:

```bash
docker compose up -d
```

Для проверки состояния контейнеров:

```bash
docker compose ps
```

Должны быть запущены банковский симулятор и MySQL.

### 2. Запуск приложения

В отдельном терминале из корневой папки проекта выполнить:

```bash
java -jar aqa-shop.jar
```

После успешного запуска приложение будет доступно по адресу:

`http://localhost:8080`

Терминал с запущенным приложением необходимо оставить открытым.

## Запуск автоматизированных тестов

Открыть новый терминал в корневой папке проекта и выполнить:

```bash
./gradlew clean test
```

Для Windows PowerShell:

```powershell
.\gradlew clean test
```

Часть тестов может завершаться с ошибкой вследствие обнаруженных дефектов тестируемого приложения.

## Формирование отчёта Allure

После выполнения тестов запустить:

```bash
./gradlew allureServe
```

Для Windows PowerShell:

```powershell
.\gradlew allureServe
```

После формирования отчёта Allure откроется в браузере.

Для остановки сервера Allure необходимо нажать `Ctrl + C` в терминале.

## Тестовые карты

Для тестирования используются следующие карты:

- `4444 4444 4444 4441` — статус `APPROVED`;
- `4444 4444 4444 4442` — статус `DECLINED`.
